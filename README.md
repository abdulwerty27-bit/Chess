# NEXUS CHESS — Crown Edition

## Аватары ботов и тренера
- Все боты отображаются с аватаром в выборе соперника; у каждого свой цветовой фон и значок.
- Аватар выбранного бота показывается рядом с доской во время игры и в режиме «Игра с тренером».
- В разделе «Обучение» выбранный аватар также отображается в карточке тренера и во время уроков.
- Для Магнуса Карлсена, Хикару Накамуры и Бобби Фишера используются портреты; если фото не загрузится, останется значок.

## Что обновлено
- Добавлены две новые модели фигур: «Турнирные Staunton» и «Деревянные Staunton». Они находятся в **Темы → Фигуры**.
- Базовый звук хода заменён на более натуральный деревянный щелчок/постановку фигуры. Добавлены ещё два варианта звука движения по деревянной доске; остальные звуковые профили сохранены.
- Для Магнуса Карлсена, Хикару Накамуры и Бобби Фишера добавлены реальные портреты. Если устройство без интернета или источник недоступен, остаётся эмодзи-аватар.
- Все обычные боты слегка усилены: немного меньше случайных неточностей и чуть больше времени на расчёт. Их уровни не были резко изменены. Экспертные профили оставлены отдельным режимом.
- Добавлена система корон: победа над ботом даёт +1 корону; каждая подсказка или отмена хода снимает 1 корону; поражение/ничья не дают награды. Баланс сохраняется на устройстве и показывается рядом с именем игрока и в сообщении результата.

## Важно о звуке и фигурах
Базовый звук — собственная процедурная имитация деревянного хода, а не скопированный аудиофайл Chess.com. Фигуры Staunton нарисованы для этого проекта. Портреты загружаются с Wikimedia Commons; для них нужен интернет. Источники и лицензии указаны в `ASSET-CREDITS.md`.

## О движке
Боты используют встроенный поисковый движок HTML-проекта, а не Stockfish. Небольшое усиление не превращает их в точные копии реальных шахматистов. Указанные рейтинги — игровые ориентиры, а не официальные рейтинги Elo.

## GitHub Pages
Можно публиковать содержимое папки `www` как статический сайт. Для корня репозитория скопируйте `www/index.html` в корень либо настройте Pages на папку `www`.

## APK через GitHub Actions
1. Создайте репозиторий GitHub и загрузите в него все файлы из архива, включая скрытую папку `.github`.
2. Откройте вкладку Actions и разрешите workflow, если GitHub попросит.
3. Запустите `Build Android APK` через Run workflow (или сделайте push в main).
4. После завершения откройте успешный запуск → Artifacts → `nexus-chess-debug-apk`.
5. Скачайте APK из артефакта.

Это тестовая debug-сборка. Для Google Play потребуется release-сборка с подписью.
